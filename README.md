# Wishstar / 愿望星

一个无需登录的私人愿望星空。每天写下一个愿望，一两年后再回头看看曾经的期待。

- 每天一个愿望，未提交内容自动保存为草稿
- 愿望通过 IndexedDB 保存在当前浏览器，不会上传服务器
- 支持星空筛选、时光回望和愿望实现状态
- 支持 JSON 导出，以及合并或覆盖导入
- 清理浏览器或更换设备前，请先导出备份

- 本地开发：`npm install && npm run dev`
- 自动测试：`npm test`
- 生产构建：`npm run build`
- 在线体验：<https://yananetlab.github.io/wishstar/>
